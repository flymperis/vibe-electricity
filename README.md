# Vibe Electricity ⚡

Self-hosted ιστορικό για τους λογαριασμούς ρεύματος. Ανεβάζεις τον λογαριασμό στο
[Paperless-ngx](https://docs.paperless-ngx.com/) και το Vibe Electricity διαβάζει από αυτόν κιλοβατώρες,
χρεώσεις, τιμές ανά kWh, ενδείξεις μετρητή, δημοτικά τέλη, ΦΠΑ και τα υπόλοιπα στοιχεία. Τα κρατά σε
πίνακες και φτιάχνει γραφήματα για την πορεία της κατανάλωσης και του κόστους.

- **Επισκόπηση**: τελευταίος λογαριασμός, kWh/ημέρα σε σύγκριση με τον προηγούμενο μήνα και με τον ίδιο μήνα πέρσι,
  πραγματικό κόστος ανά kWh, μέσο μηνιαίο κόστος, πού πήγαν τα χρήματα.
- **Λογαριασμοί**: όλοι οι λογαριασμοί, με φίλτρο ανά χρονιά και εξαγωγή σε CSV για Excel.
  Κάθε λογαριασμός έχει όλα τα πεδία του, τους ελέγχους, link στο Paperless, διόρθωση με το χέρι και ξαναδιάβασμα.
- **Ανάλυση**: σύγκριση ίδιου μήνα ανά χρονιά, εξέλιξη τιμών (συνολική, ενέργειας, δικτύου), κόστος ανά μήνα και
  χρονιά, σύνολα ανά έτος.
- Δουλεύει σε υπολογιστή και κινητό, σε φωτεινό και σκοτεινό θέμα.

## Πώς διαβάζει τους λογαριασμούς

Το Paperless έχει ήδη κάνει OCR στο PDF. Το Vibe Electricity διαβάζει αυτό το κείμενο, και **δεν αλλάζει ποτέ τίποτα
στο Paperless**.

1. **Κανόνες για τη ΔΕΗ.** Οι λογαριασμοί της ΔΕΗ (myΔΕΗ PDF) διαβάζονται με κανόνες, χωρίς AI, σε λιγότερο από ένα
   δευτερόλεπτο. Καλύπτουν απλή και κλιμακωτή χρέωση, επιδότηση, στρογγυλοποιήσεις και OCR που χωρίζει τα ψηφία με κενά.
2. **AI για τα υπόλοιπα.** Λογαριασμοί άλλων παρόχων, ή μια νέα μορφή που οι κανόνες δεν καλύπτουν, πάνε σε τοπικό
   μοντέλο του [Ollama](https://ollama.com/) (προεπιλογή `qwen3:8b`). Το μοντέλο απαντά σε σταθερό σχήμα JSON. Αν οι
   κανόνες βρήκαν τα περισσότερα πεδία, το AI συμπληρώνει μόνο όσα λείπουν.
3. **Έλεγχοι.** Κάθε ανάγνωση ελέγχεται με τα ίδια τα νούμερα του λογαριασμού:
   - προμήθεια + ρυθμιζόμενες + διάφορα + ΦΠΑ = σύνολο
   - πάγιο + ενέργεια ± επιδότηση = προμήθεια
   - ΑΔΜΗΕ + ΔΕΔΔΗΕ + ΥΚΩ + ΕΤΜΕΑΡ = ρυθμιζόμενες
   - διαφορά ενδείξεων μετρητή = kWh, και kWh × τιμή = χρέωση ενέργειας
   - οι ημέρες ταιριάζουν με την περίοδο

   Αν όλα ταιριάζουν, ο λογαριασμός παίρνει ✓. Αν κάτι δεν ταιριάζει, φαίνεται ποιο είναι και διορθώνεται από το UI.
   Οι διορθώσεις κρατιούνται και όταν ο λογαριασμός ξαναδιαβαστεί.

Αν το ίδιο PDF ανέβει δύο φορές, ή ο ίδιος λογαριασμός (ίδιος αριθμός) ανέβει από άλλο αρχείο, μετρά μία φορά.
Έγγραφα με το tag που δεν είναι λογαριασμοί ρεύματος, π.χ. νερού, παραλείπονται.

## Εγκατάσταση

Χρειάζεσαι Paperless-ngx με ένα API token, και προαιρετικά Ollama.

```bash
git clone https://github.com/flymperis/vibe-electricity.git
cd vibe-electricity
cp .env.example .env      # PAPERLESS_URL, PAPERLESS_TOKEN, OLLAMA_URL ...
docker compose up -d      # ή: podman-compose up -d
```

Το UI ανοίγει στο `http://<server>:8002`. Στην πρώτη εκκίνηση διαβάζονται όλα τα έγγραφα του Paperless με το tag
`Electricity` (ρυθμίζεται).

Για Podman Quadlet (systemd service, ξεκινά στο boot) δες το [deploy/quadlet/README.md](deploy/quadlet/README.md).
Το update γίνεται με `deploy/update.sh`, που κρατά backup της βάσης πριν το `git pull` και το rebuild.

## Σύνδεση με το Paperless

Νέοι λογαριασμοί φτάνουν με δύο τρόπους:

- **Webhook, άμεσα.** `POST /api/webhook` με JSON `{"document_id": 123}`. Δέχεται και `{"doc_url": ".../documents/123/"}`.
  Αν ορίσεις `WEBHOOK_SECRET`, το webhook απαιτεί και το header `X-Webhook-Secret`. Μπορεί να το στείλει:
  - το [paperclass](https://github.com/flymperis/paperclass), που ταξινομεί τα έγγραφα του Paperless με AI και προωθεί
    όσα παίρνουν το tag `Electricity`, ή
  - ένα Paperless Workflow (trigger *Document Updated*, φίλτρο στο tag, action *Webhook*).
- **Περιοδικός έλεγχος, ως εφεδρεία.** Κάθε 30 λεπτά (ρυθμίζεται) ελέγχει το Paperless για νέα ή αλλαγμένα έγγραφα με το tag.
  Το κουμπί ↻ κάνει τον ίδιο έλεγχο αμέσως.

## Ρυθμίσεις

| Μεταβλητή | Προεπιλογή | |
|---|---|---|
| `PAPERLESS_URL` / `PAPERLESS_TOKEN` | | API του Paperless |
| `PAPERLESS_PUBLIC_URL` | = `PAPERLESS_URL` | η διεύθυνση του Paperless στον browser, για τα links |
| `PAPERLESS_TAG` | `Electricity` | tag των λογαριασμών ρεύματος (και από το UI) |
| `OLLAMA_URL` / `OLLAMA_MODEL` | `qwen3:8b` | AI για άγνωστες μορφές (και από το UI) |
| `LLM_ENABLED` | `true` | (και από το UI) |
| `SYNC_INTERVAL_MINUTES` | `30` | (και από το UI) |
| `WEBHOOK_SECRET` | | |
| `TIMEZONE` | `Europe/Athens` | για τις ώρες στο UI |

Το UI δεν έχει login. Είναι φτιαγμένο για το τοπικό δίκτυο, όπως και τα υπόλοιπα self-hosted εργαλεία του ίδιου
server. Μην το εκθέτεις στο internet χωρίς reverse proxy με authentication.

## API

- `GET /api/bills`: όλοι οι λογαριασμοί σε JSON
- `GET /export.csv`: το ίδιο σε CSV (`;`, UTF-8 με BOM για Excel)
- `POST /api/webhook`: ανάγνωση ενός εγγράφου
- `GET /healthz`

## Ανάπτυξη

```bash
python -m venv .venv && .venv/bin/pip install -r requirements.txt pytest
.venv/bin/python -m pytest
.venv/bin/uvicorn vibe_electricity.main:app --reload
```

Τα test fixtures στο `tests/fixtures/` είναι κείμενα λογαριασμών με ψεύτικα ονόματα, διευθύνσεις και αριθμούς.
